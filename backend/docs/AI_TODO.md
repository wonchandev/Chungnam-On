## 1. 챗봇 고도화

### 검색(RAG)
- [x] **P0** 행정 가이드 초안 콘텐츠 등록 (비자·체류, 건강보험, 근로계약, 임금 체불 대응)
- [x] **P1** 임베딩 기반 의미 검색 도입 (키워드 검색 대체)
- [x] **P1** 긴 가이드의 문단 단위 분할 및 색인
- [x] **P1** 검색 결과 재순위화 (관련도 낮은 문서 제외)
- [x] **P2** 다국어 질의 직접 검색 (한국어 번역 단계 제거) — 임베딩 검색 시 번역 없이 질의

### 도구 호출(기능 연동)
- [x] **P0** 공고 검색 도구 연동 ("내 근처 일당 높은 공고")
- [x] **P1** 내 지원 현황 조회 도구 연동
- [x] **P1** 지원·관심 공고 등록 도구 연동 (사용자 확인 단계 포함)
- [x] **P2** 근무 일정·급여 계산 도구 연동 — 급여 계산(`estimate_pay`)·지원 현황 조회로 대체, 근무 일정 캘린더는 미구현

### 답변 품질
- [x] **P0** 답변 출처 표기 (참고 가이드 링크·제목)
- [x] **P0** 답변 피드백 수집 (👍/👎, 사유)
- [x] **P1** 사용자 정보 반영 개인화 (비자 종류, 거주지역, 사용 언어)
- [x] **P1** 불확실 답변 처리 (모르는 내용은 공식 창구 안내)
- [x] **P2** 후속 질문 추천

### 안전장치
- [x] **P0** 사용자별 호출 횟수 제한 (비용 보호)
- [x] **P0** 프롬프트 인젝션 방어 (가이드·사용자 입력 분리)
- [x] **P1** 법률 판단·진단성 질문 거절 규칙 및 안내 문구
- [x] **P1** 개인정보(여권번호·외국인등록번호) 입력 감지 및 마스킹
- [x] **P2** 부적절 질문 신고 및 관리자 검토 화면

### 대화 관리
- [x] **P1** 긴 대화의 요약 및 컨텍스트 길이 관리 — 글자 수 예산으로 이력 절단만 구현 (요약은 미구현)
- [x] **P1** 대화 제목 자동 생성
- [x] **P2** 대화 내보내기

### 비용 · 운영
- [ ] **P1** 모델 선택 정책 (단순 질문 소형 모델, 복잡 질문 대형 모델)
- [ ] **P1** 토큰 사용량·비용 로그 및 집계
- [ ] **P1** 평가용 질문 세트 구축 및 정확도 측정
- [ ] **P2** 오류·지연 모니터링 알림

## 2. 번역 고도화

### 정확도
- [ ] **P0** 발신 언어 자동 감지 (설정 언어와 실제 입력 언어 불일치 대응)
- [ ] **P0** 현장 용어집 구축 (일당, 4대보험, 안전모, 휴게시간 등) 및 번역 적용
- [ ] **P1** 문맥 반영 번역 (공고 어조, 존댓말, 숫자·단위 보존)
- [ ] **P1** 오번역 신고 및 관리자 교정 기능
- [ ] **P1** 원문 보기·번역 보기 전환 데이터 제공
- [ ] **P2** 번역 품질 비교 평가 (구글 / OpenAI)

### 속도 · 안정성
- [ ] **P0** 다국어 번역 일괄 요청 (언어별 개별 호출 → 묶음 호출)
- [ ] **P0** 공고 번역 백그라운드 처리 (등록 응답 지연 제거)
- [ ] **P1** 번역 실패 재시도 및 재처리 큐
- [ ] **P1** 외부 API 타임아웃·쿼터 초과 대응
- [ ] **P1** 번역 캐시 정책 정비 (원문 정규화, 만료, 용어집 변경 시 무효화)
- [ ] **P2** 자주 쓰는 문장 사전 번역 (미리 계산)

### 채팅 번역
- [ ] **P1** 번역 지연 시 원문 우선 표시 후 번역 갱신
- [ ] **P1** 번역 언어쌍 자동 제안 (상대 언어 기준)
- [ ] **P2** 이모티콘·약어·은어 처리 규칙

### 음성 · 사진
- [ ] **P1** 음성 파일 형식 서버 변환 및 길이 제한 확장
- [ ] **P1** 사진 속 글자 영역별 번역 결과 제공
- [ ] **P2** 번역문 음성 재생 (TTS)
- [ ] **P2** 실시간 음성 번역 (스트리밍)

### 비용 · 운영
- [ ] **P1** 번역 호출량·비용 집계 및 한도 설정
- [ ] **P1** 엔진 전환 설정 정리 (구글 / OpenAI, 공고·채팅별 선택)
- [ ] **P2** 번역 품질 모니터링 지표 (오번역 신고율)

## 3. 진행 순서 제안

1. **기반:** 행정 가이드 콘텐츠 등록, 호출 횟수 제한, 일괄·백그라운드 번역
2. **품질:** 출처 표기, 피드백 수집, 언어 자동 감지, 현장 용어집
3. **기능:** 공고 검색 도구 연동, 임베딩 검색
4. **운영:** 비용 집계, 평가 질문 세트, 모니터링
