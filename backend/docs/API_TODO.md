# 충남온 Backend API TODO

디자인(피그마 PDF 11장) + 서비스 개요 기준으로 정리한 백엔드 API 작업 목록입니다.
- 공통 prefix: `/api/`, 인증: JWT Bearer, 목록은 페이지네이션 (`?page=`)
- 우선순위: **P0** = MVP 필수 / **P1** = 핵심 확장 / **P2** = 후순위
- 담당 앱은 `apps/<앱>` 기준. 작업 전 Issue 등록 → `feat/...` 브랜치 → `develop` 대상 PR

## 3. 일용직 구인·구직 (`jobs`)

### 3-1. 모델
- [ ] **P0** `Company`(사업주/인력사무소), `JobPost`, `Application`, `Bookmark`, `JobCategory`
- [ ] **P0** JobPost 필드: 제목, 회사, 대표이미지, 급여유형(시급/일급)+금액, 근무지(시군구+상세주소+위경도), 근무일/시작일/기간, 근무시간(시작·종료·휴게), 직무 설명, 모집인원, 마감일, 상태(모집중/마감/취소), 긴급 여부, 태그
- [ ] **P0** 태그: 초보가능, 친구와 함께, 점심제공, 인근지역우대, 야간근무
- [ ] **P0** 업종 카테고리: 제조·생산, 건설현장, 농업·축산, 물류·배송, 매장관리·판매, 안전요원 등

### 3-2. 공고 (사업주)
- [ ] **P0** `POST /api/jobs/` 공고 등록 (사업주/인력사무소만)
- [ ] **P0** `PATCH/DELETE /api/jobs/{id}/` 수정·삭제 (본인 공고만)
- [ ] **P0** `POST /api/jobs/{id}/close/` 마감 처리, 마감일 지나면 자동 마감 (스케줄러)
- [ ] **P1** 공고 복사(재등록), 내 공고 목록 `GET /api/jobs/mine/`

### 3-3. 공고 조회 (근로자) — 홈 / 구인구직 화면
- [ ] **P0** `GET /api/jobs/` 목록 + 필터/정렬
  - 필터: 지역(시군구), 업종, 급여유형, 근무기간, 요일, 태그, 키워드 검색
  - 정렬: 최신순, 급여순, 마감임박순, 거리순
  - 응답에 `총 N건`(count), 북마크 여부, 회사 온도 포함
- [ ] **P0** `GET /api/jobs/{id}/` 상세 (채용 공고 화면: 직무/모집인원/근무시간/기간/위치/급여)
- [ ] **P0** `GET /api/jobs/urgent/` 긴급 채용·마감임박 (홈 "긴급 채용중" 캐러셀)
- [ ] **P0** `GET /api/jobs/popular-categories/` 지금 많이 찾는 일자리 (제조생산/건설/농업/물류)
- [ ] **P1** `GET /api/jobs/recommended/` 나에게 딱 맞는 일자리 / AI 추천 (프로필·지역·이력 기반, 초기엔 규칙 기반)
- [ ] **P1** 홈 배너용 `GET /api/jobs/ticker/` 실시간 신규 공고 (시급/일급 + 지역)
- [ ] **P1** 최근 본 공고, 인기 검색어

### 3-4. 신청 / 승인
- [ ] **P0** `POST /api/jobs/{id}/apply/` 지원하기 (중복 지원 방지, 마감·정원 검증)
- [ ] **P0** `DELETE /api/applications/{id}/` 지원 취소
- [ ] **P0** `GET /api/applications/mine/` 내 구직활동 (상태별: 대기/승인/거절/완료)
- [ ] **P0** `GET /api/jobs/{id}/applications/` 사업주: 지원자 목록
- [ ] **P0** `PATCH /api/applications/{id}/` 사업주: 승인/거절 (승인 시 정원 체크, 알림 발송)
- [ ] **P1** 출근 확인/근무 완료 처리 → 후기 작성 가능 상태로 전환
- [ ] **P1** 지원 시 문의 채팅방 자동 생성 연동

### 3-5. 관심 공고 / 인력사무소
- [ ] **P0** `POST/DELETE /api/jobs/{id}/bookmark/` 별 토글
- [ ] **P0** `GET /api/jobs/bookmarks/` 관심 공고 목록
- [ ] **P1** `GET /api/agencies/` 인력사무소 목록/상세 (구인구직 화면 "인력사무소" 탭), 소속 공고, 온도

## 5. 다국어 소통 / 채팅 (`translation`, 채팅은 `chat` 앱 신규 권장)

### 5-1. 채팅
- [ ] **P0** `chat` 앱 생성: `ChatRoom`(공고·참여자), `Message`(원문, 원문언어, 발신자, 읽음)
- [ ] **P0** `POST /api/chat/rooms/` 문의하기 → 채팅방 생성/기존 방 반환 (공고 기준)
- [ ] **P0** `GET /api/chat/rooms/` 최근 대화 목록 (상대 이름, 마지막 메시지, 시간, **안읽음 수**)
- [ ] **P0** `GET /api/chat/rooms/{id}/messages/` 메시지 이력 (원문 + 번역본 함께, 커서 페이지네이션)
- [ ] **P0** WebSocket `ws/chat/{room_id}/` (Django Channels + Redis): 실시간 송수신, 온라인 상태, 읽음 처리
- [ ] **P0** 메시지 저장 시 상대방 언어로 자동 번역 → `MessageTranslation(message, lang, text)`
- [ ] **P0** `PATCH /api/chat/rooms/{id}/translation/` 번역 언어쌍 설정 (한국어↔태국어 등)
- [ ] **P1** 추천 단어/빠른 답변 `GET /api/chat/quick-replies/` ("위치는 어디인가요?", "급여는 어떻게 되나요?")
- [ ] **P1** 파일/이미지 첨부 (`+` 버튼), 전화 연결(번호 노출 정책 결정)
- [ ] **P1** 새 메시지 푸시 알림, 채팅방 나가기/차단/신고

### 5-2. 번역
- [ ] **P0** 번역 엔진 선정·추상화 (`TranslationService`: Papago/Google/DeepL/LLM) + 결과 캐시
- [ ] **P0** `POST /api/translate/text/` 텍스트 번역 (source, target, text)
- [ ] **P0** 공고 등록/수정 시 제목·설명 자동 번역 저장 (`JobPostTranslation`), 조회 시 사용자 언어로 응답
- [ ] **P1** `POST /api/translate/voice/` 음성 번역 (STT → 번역 → 선택적 TTS)
- [ ] **P1** `POST /api/translate/image/` 사진 번역 (OCR → 번역)
- [ ] **P1** `GET /api/phrases/` 자주 쓰는 현장 표현 (카테고리별, 다국어 시드 데이터, 검색)
- [ ] **P1** 지원 언어 목록 `GET /api/languages/`

### 5-3. 언어 교육 (다국어 소통 화면 상단 카드)

## 추천 진행 순서

1. **기반**: 공통 에러/업로드/시군구 데이터, 회원 확장 (0, 1)
2. **구인구직 코어**: 모델 → 공고 CRUD → 목록/상세/필터 → 지원/승인 → 북마크 (3)
3. **지도**: 지오코딩 → nearby → 클러스터 (4)
4. **채팅 + 번역**: 번역 서비스 → 채팅 REST → WebSocket → 공고 자동번역 (5)
5. **행정관리/AI**: 가이드 콘텐츠 → 대시보드 → 챗봇 (6)
6. **평판/커뮤니티/언어교육**: (2, 7, 5-3)

## 팀 협의가 필요한 결정

- 번역/STT/OCR/LLM 외부 API 선정 및 비용 (예산, 캐싱 전략)
- 지도 SDK(카카오/네이버)와 지오코딩 제공 주체 (프론트 vs 서버)
- PostGIS 도입 여부 (클러스터 규모에 따라)
- 채팅 전화 연결 시 개인정보(전화번호) 노출 정책
- 지원 시 필요한 서류/비자 검증 범위 (불법체류·고용허가 확인 책임)
- 인력사무소와 사업주 계정 구분 및 사업자 인증 방식
